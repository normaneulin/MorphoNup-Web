The idea

Chromatin means "coloured material". Walther Flemming named it around 1880 because it takes up dyes so strongly. In the most common tissue stain, haematoxylin and eosin (H&E), chromatin turns deep blue-violet while the rest of the cell turns pink. The palette comes from that stain, on the pale glass of a microscope slide.

The logo is a nucleosome seen from above. The histone core is split into four pieces, the four histone pairs you see from the top, and the gap between them is an M. The core is eosin pink because eosin stains proteins, and the DNA is haematoxylin violet because haematoxylin stains DNA. The DNA ribbon wraps the core 1.65 turns, like the 147 bp of a real nucleosome, and it is as wide as the minor groove of a real nucleosomal sequence from the benchmark ({{SEQ_NAME}}, H. sapiens), computed by DNAshapeR. The light dot marks the dyad, the centre of the 147 bp.

How it is made

The four histone pieces are the author's own drawing (design/logo/histone-core.svg), used as drawn. The DNA ribbon is computed from the groove width of a real sequence by scripts/make_brand_assets.py, so the same script makes the logo, the favicon of the site and this board.

On the dark theme the core turns a lighter eosin and the DNA turns pale lilac, so the mark keeps the same contrast instead of being inverted.

Name and lockups

The wordmark is set in one weight; the capital N already marks where "Nup" (nucleosome positioning) starts, so no second colour is needed.
